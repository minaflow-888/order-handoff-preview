# Order Handoff Automation — Case Study

A bilingual EN/SV portfolio case study for a functional Make.com demonstration.

## Implemented workflow

HubSpot Closed Won → retrieve deal and associations → validate contact and email → check the deal ID in Google Sheets → send customer email in Brevo → update HubSpot → log the result → send internal email.

The scenario also contains logs for missing contact, missing email and failed customer email, HubSpot update or internal email actions.

## Files

- `index.html` — GitHub Pages entry file
- `content.jsx` — English and Swedish content
- `order-handoff-theme.css` — local orange/dark visual identity
- `v2-*.jsx` — page sections and interactions
- `assets/` — Mina logo, preview images and real Make.com screenshots
- `.nojekyll` — keeps underscore-prefixed design-system files available on GitHub Pages

## Transparency

This is a portfolio demonstration tested with demonstration records. It was not built for a live client and does not claim measured client results.
